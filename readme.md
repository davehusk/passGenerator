# 📜 Password Generator CLI: A Handy Tool by David Husk 🌟

Welcome to  **Password Generator CLI** , a simple yet powerful Node.js tool for generating secure, customizable passwords right from your terminal! 🎉 This project was crafted with care by  **David Husk** . 💻✨

---

## 🚀 Features

* **Customizable Length** : Generate passwords with your desired length. 🧮
* **Include Uppercase Letters** : Add uppercase letters to strengthen your password. 🔠
* **Include Numbers** : Use digits for extra security. 🔢
* **Include Symbols** : Add special characters to make passwords extra robust! 🔐
* **Quick Help** : Access an intuitive help menu anytime. 📖

---

## 🛠️ Installation

1. **Clone the Repository** :

```bash
   git clone https://github.com/your-repo/password-generator-cli.git
   cd password-generator-cli
```

1. **Install Dependencies** :

```bash
   npm install
```

1. **Run the Script** :

```bash
   node generatePassword.js
```

---

## 📋 Usage

Run the command with any combination of options below: 🧑‍💻

```bash
node generatePassword.js [--length <number>] [--uppercase] [--numbers] [--symbols]
```

### Options:

* `--length <number>`: Specify the password length (default: 8). 🧮
* `--uppercase`: Include uppercase letters (e.g., `A, B, C`). 🔠
* `--numbers`: Include numbers (e.g., `0-9`). 🔢
* `--symbols`: Include special characters (e.g., `!@#$%^&*`). 🔐
* `--help`: Display the help menu. 📖

---

## 🧑‍🎨 Examples

### 1.  **Default Password** :

```bash
node generatePassword.js
```

✨ *Generates an 8-character password with only lowercase letters.* ✨

---

### 2.  **Custom Length** :

```bash
node generatePassword.js --length 12
```

🔢 *Generates a 12-character password with only lowercase letters.* 🔢

---

### 3.  **Include Uppercase Letters** :

```bash
node generatePassword.js --length 10 --uppercase
```

🔠 *Generates a 10-character password with lowercase and uppercase letters.* 🔠

---

### 4.  **Fully Customized Password** :

```bash
node generatePassword.js --length 16 --uppercase --numbers --symbols
```

🔐 *Generates a 16-character password with lowercase, uppercase, numbers, and symbols.* 🔐
